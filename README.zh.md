## 关于

本仓库包含完整历史档案。

**注意：** 最新2个协议也可在collector仓库查看。

## 协议类型

### 最终协议
每**周一 13:45 UTC**（7天）。
- 格式：`{week_end}.md`

### 临时协议
每**周五 13:45 UTC**（5天）。
- 格式：`{week_end}.interim.md`

## 时间表

| 日期 | UTC | 操作 |
|------|-----|------|
| 周一 | 13:45 | 最终 |
| 周一 | 13:50 | 翻译 |
| 周一 | 14:00 | 发布 |
| 周五 | 13:45 | 临时 |
| 周五 | 13:50 | 翻译 |
| 周六 | 08:00 | 发布 |
