## About

This repository contains the **complete historical archive** of automatically generated weekly protocols monitoring the development gap between AI and Humanity.

Protocols are generated by [human-ai-monitor-collector](https://github.com/VQQLK/human-ai-monitor-collector) and published here automatically via GitHub Actions.

**Note:** The latest 2 protocols (FINAL + INTERIM) are also available in the collector repo as a "living showcase".

## Protocol Types

### Final Protocols
Generated every **Monday 13:45 UTC** (previous week, 7 days).
- Format: `{week_end}.md`
- Languages: English, Russian, Chinese

### Interim Protocols
Generated every **Friday 13:45 UTC** (current week, 5 days).
- Format: `{week_end}.interim.md`
- Purpose: Mid-week snapshot
