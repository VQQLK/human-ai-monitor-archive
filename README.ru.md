## О проекте

Этот репозиторий содержит **полный исторический архив** протоколов о разрыве между ИИ и Человечеством.

**Примечание:** Последние 2 протокола также доступны в collector.

## Типы протоколов

### Финальные
Каждый **понедельник 13:45 UTC** (7 дней).
- Формат: `{week_end}.md`

### Промежуточные
Каждую **пятницу 13:45 UTC** (5 дней).
- Формат: `{week_end}.interim.md`

## Расписание

| День | UTC | Действие |
|------|-----|----------|
| Пн | 13:45 | Финальный |
| Пн | 13:50 | Переводы |
| Пн | 14:00 | Публикация |
| Пт | 13:45 | Промежуточный |
| Пт | 13:50 | Переводы |
| Сб | 08:00 | Публикация |
